# Data availability

The original coursework used market data downloaded from Bloomberg Terminal, including EURO STOXX 50 options, EUR OIS quotes, Euribor, VSTOXX and Crédit Agricole CDS information.

Those raw input files are intentionally not redistributed in this public portfolio version.

The unchanged MATLAB scripts expect the following original coursework files in their working directory:

- `Dataset.xlsx`
- `EUSTX.xlsx`
- `VSTOXX.xlsx`
- `EURIBOR3M.xlsx`
- `curvaEUROIS.xlsx`
- `CDSV_Credit_Agricole.xlsx`

The figures tracked in `figures/` are generated analytical outputs reproduced from the submitted coursework report; Bloomberg Terminal screenshots are not included.
