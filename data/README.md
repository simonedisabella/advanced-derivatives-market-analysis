# Data availability

The original coursework used third-party market data, including EURO STOXX 50 options, EUR OIS quotes, Euribor, VSTOXX and issuer credit data.

Those raw input files are intentionally not redistributed in this public portfolio version.

The unchanged MATLAB scripts expect the following original coursework files in their working directory:

- `Dataset.xlsx`
- `EUSTX.xlsx`
- `VSTOXX.xlsx`
- `EURIBOR3M.xlsx`
- `curvaEUROIS.xlsx`
- `CDSV_Credit_Agricole.xlsx`

The figures tracked in `figures/` are generated analytical outputs reproduced from the submitted coursework report; third-party terminal screenshots are not included.
